TokenMapper Audio Demo

This folder contains audio samples demonstrating cross model token translation produced by TokenMapper.

Contents

index.html – Interactive demo page for listening to all audio samples.

audio files – Ground truth , original reconstructions and cross model translations used for qualitative evaluation.

How to use

Open index.html in any modern browser (Chrome, Firefox, Edge). No installation is required.


All samples are taken from the evaluation datasets described in the paper.

Audio is provided for demonstration purposes only and complements the quantitative WER and UTMOS results reported in the paper.
